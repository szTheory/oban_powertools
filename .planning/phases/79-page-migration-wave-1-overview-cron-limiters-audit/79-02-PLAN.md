## Artifacts this phase produces

- New public query symbol `ObanPowertools.Audit.page/2` with arguments `(filters, opts)`. It returns a plain map with exactly `events`, `total_count`, `page`, `page_size`, `total_pages`, `previous?`, and `next?`; `page_size` is always 20.
- Existing `Audit.list/2`, `list_all/1`, and `list_all/2` remain public and compatible, but their newest-first ordering gains the deterministic `id DESC` tie-break where applicable.
- New public presenter symbols `present_overview_bucket/1`, `present_cron_action/1`, `present_cron_result/1`, `present_limiter_blocker/1`, `present_audit_row/2`, and `present_audit_detail/2` in `ControlPlanePresenter`.
- `present_overview_bucket/1` output fields: `id`, `kind`, `title`, `count`, `summary`, `impact`, `observed_at`, `observed_datetime`, `domain`, `status`, `severity`, `completeness`, `ownership`, `sample_count_label`, `next_step_label`, `next_step_path`, and bounded `exemplars`.
- `present_cron_action/1` output fields: closed `kind: :pause | :resume | :run_now`, `confirm_label`, `dismiss_label`, `title`, `consequence`, `support_boundary`, `pending_copy`, and `intent: :warning`; internal kind is not rendered as a raw action atom.
- `present_cron_result/1` output fields: closed lifecycle `state`, `message`, optional `recorded_result`, optional `recovery`, optional `audit_href`, and optional clean-success `receipt`; it never claims that accepted run-now work ran.
- `present_limiter_blocker/1` output fields: `id`, `evidence_kind: :current`, `label`, `summary`, optional `affected_scope`, `clearing_condition`, and `evidence_source`. Any technical code used to classify a known blocker is consumed internally and omitted from Phase 79 page maps and rendered HTML.
- `present_audit_row/2` output fields: `id`, `event_label`, `target_label`, optional `target_href`, `actor`, `reason_summary`, `recorded_at`, `recorded_datetime`, `evidence_href`, and `evidence_label`.
- `present_audit_detail/2` output is accepted by existing `normalize_audit_entry/1` and includes `sentence`, `outcome`, `outcome_state`, `actor`, `action`, `target`, `reason`, `source`, `correlation`, `occurred_at`, `occurred_datetime`, `recorded_at_label: "Recorded at"`, and allowlisted `changes`/`evidence`.
- Existing normalized blocker maps gain optional `affected_scope`; existing normalized audit maps gain `recorded_at_label` and exact fallbacks for absent source/correlation. Existing callers without the optional fields remain valid.
- No new dependency, database schema/index, route, page mutation, authorization policy, provider adapter, or stateful component is introduced.
