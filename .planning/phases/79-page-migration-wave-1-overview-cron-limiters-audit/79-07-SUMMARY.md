## Decisions Made

- The production LiveViews keep their verified semantic trees. The CSS contract groups canonical `.obpt-page*` symbols with the stable page classes and IDs already shipped by Plans 79-03 through 79-06.
- The page root owns only composition: gaps, columns, wrapping, minimum sizing, read measure, and placement. Buttons, links, tables, filters, surfaces, status, dialogs, drawers, and scroll regions remain styled and controlled by their shared components.
- Wide scan/detail placement uses dense row auto-placement so a conditional detail occupies the open second column beside its table while full-width banners, filters, errors, and receipts retain source order.
- Overview direct exemplar lists use their accessible `aria-label` suffix as the stable production seam; separators apply only between direct rows and use the semantic page separator token.
- High contrast changes only `--obpt-color-page-separator`; layout is untouched. Page-control transitions use `--obpt-motion-duration-instant` for both media-preference and explicit root motion-reduction paths.
