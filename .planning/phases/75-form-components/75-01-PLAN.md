|---|---|---|
| XSS via labels, hints, errors, values, or options | high | Hostile render assertions require HEEx escaping and forbid raw HTML APIs. |
| Visual-policy injection through `class`/`style` | high | Rest-filter tests require these attrs to be absent while semantic attrs survive. |
| ARIA spoofing or broken associations | medium | Exact label, described-by, and invalid-state assertions use final caller-overridden ids. |
| Hidden unchecked value mutates row selection | high | Separate named boolean and event-driven render assertions gate hidden input emission. |
| Fake combobox communicates nonexistent behavior | medium | Filter assertions forbid popup roles/attributes. |
</threat_model>
