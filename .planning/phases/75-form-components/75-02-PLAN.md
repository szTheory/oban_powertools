## Locked decision coverage

- D-01: Implement forms in the separate `ObanPowertools.Web.Components.Forms` module, beside rather than inside `Primitives`.
- D-02: Keep every form component stateless; parent LiveViews retain changesets/maps, events, authorization, mutation, URL, and persistence ownership.
- D-03: Make `field={@form[:field]}` over `Phoenix.HTML.FormField` the normal API and derive id, name, value, and errors from it.
- D-04: Export the narrow typed wrappers `input/1`, `textarea/1`, `select/1`, `checkbox/1`, `radio_group/1`, `switch/1`, `field_group/1`, `label/1`, `hint/1`, and `error/1`.
- D-05: Add no schema/macro form DSL.
- D-06: Permit semantic/native/rest attributes required by controls while rejecting caller `class` and `style` visual escape hatches.
- D-07: Require a non-empty visible label or associated fieldset legend; never treat placeholder text as a label.
- D-08: Derive stable hint/error ids and merge them after caller-provided `aria-describedby` tokens without duplicates.
- D-09: Render `aria-invalid="true"` only with a visible text error and token-backed non-color invalid signal.
- D-10: Use `Phoenix.Component.used_input?/1` interaction timing for field errors while allowing explicit submit/action errors.
- D-11: Render field-specific, recovery-oriented error copy through the shared error component without changing existing mutation semantics.
- D-12: Preserve native and visual distinction between disabled and read-only, with perceivable explanations for unavailable controls.
- D-13: Use native checkbox and radio inputs, including the checkbox-backed switch, rather than hand-rolled ARIA widgets.
- D-14: Emit hidden unchecked values only for named boolean fields and never for event-driven row-selection checkboxes.
- D-15: Render radio groups with `fieldset`/`legend`, no invented default, and an explicit clear option when clearing is valid.
- D-16: Restrict switch styling to immediate reversible settings, with a setting-naming label and non-color state signal.
- D-17: Provide comfortable token-backed choice hit targets, visible focus, label-click behavior, and 320px-safe wrapping.
- D-18: Implement filter-ready native text/search/select variants, not a popup combobox.
- D-19: Forbid `role="combobox"` and popup ARIA on plain filter controls.
- D-20: Exclude FilterBar, chips, multi-select, suggestions, saved filters, and filter grammar from this component phase.
- D-21: Leave canonical URL serialization, debouncing/batching, and query behavior with later page/group owners; components expose semantic values only.
- D-26: Enforce no raw visual values, host selectors/theme mutation, caller visual escape hatches, or new runtime dependencies.
