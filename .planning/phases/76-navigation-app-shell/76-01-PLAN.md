<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller assigns -> AppShell HEEx | Caller-provided actor/context/rest values cross into rendered HTML. |
| LiveView URI -> active nav | Route/current-path data determines active navigation and breadcrumbs. |
| browser events -> shell disclosure/theme state | Client-side click/key events mutate scoped shell and theme UI state. |
| support catalog -> showcase/manifest | Dev/test story metadata becomes browser selectors and VRT/a11y targets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-76-01 | Tampering | AppShell nav labels/rest attrs | mitigate | This plan creates tests requiring a closed nine-item nav model, HEEx-escaped copy, and caller `class`/`style` filtering. |
| T-76-02 | Spoofing | active route and breadcrumb | mitigate | This plan creates integration tests requiring server-derived current path and detail fallback breadcrumbs, not client-provided active flags. |
| T-76-03 | Information Disclosure | actor/context copy | mitigate | This plan creates tests requiring actor display from existing `Auth.audit_principal/1` output or `Actor context unavailable`, with no invented tenant/environment labels. |
| T-76-04 | Denial of Service | mobile disclosure/focus | mitigate | This plan creates browser contracts for skip link, collapsed tab order, Escape close, and 320px overflow. |
| T-76-05 | Information Disclosure | theme state | mitigate | This plan requires scoped `.obpt-root` theme state and existing `data-obpt-theme-choice`; no host `<html>` theme mutation is allowed. |
| T-76-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs are planned. If an executor attempts an install, stop for package legitimacy review before proceeding. |
</threat_model>
