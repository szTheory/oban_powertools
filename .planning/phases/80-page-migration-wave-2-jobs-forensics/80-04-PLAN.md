## Trust Boundaries

| Boundary | Untrusted input / protected output |
|---|---|
| Browser selection/confirm -> LiveView | forged scope/count/reason/action -> server-owned frozen scope |
| LiveView -> coordinator | authorized frozen IDs/previews -> nonlinked bounded work |
| Coordinator -> Lifeline | opaque per-target token -> independently audited mutation |
| Coordinator -> LiveView/telemetry | internal outcomes -> aggregate safe messages/buckets |

## STRIDE Threat Register — blocking threshold: high

| Threat ID | Category | Severity | Disposition | Mitigation and verification |
|---|---|---|---|---|
| T-80-04-SCOPE | Tampering | high | mitigate | IDs are frozen once, bounded with limit+1, and execution never reruns filters or trusts typed/client counts. |
| T-80-04-AUTH | Elevation of privilege | high | mitigate | Page/action/each target authorization occurs at preview; Lifeline reauthorizes execution. |
| T-80-04-LEAK | Information disclosure | high | mitigate | Separate server/display preview layers and closed messages/telemetry exclude tokens, reasons, IDs, errors, and payloads. |
| T-80-04-DOS | Denial of service | high | mitigate | Config 1..1000, max concurrency four, 30s target timeout, and 50-row result pages bound resources. |
| T-80-04-CRASH | Denial of service | high | mitigate | Named nonlinked supervisor, kill-on-timeout, crash isolation, and stale run-ref handling protect socket/application. |

| T-80-04-CONFIG | Security misconfiguration | high | mitigate | Invalid limit blocks startup with actionable error; no silent clamp or weak default occurs. |
