<interfaces>
- `DataDisplay.toast/1` currently owns the dismiss button and accepts `id`, `tone`, `urgency`, `dismiss_event`, `rest`, and `inner_block`.
- `DataDisplay.flash_group/1` accepts `id`, `flash`, `dismiss_event`, and `rest`; its current private `flash_items/1` discards the source key.
- Phoenix LiveView handles `lv:clear-flash` per item only for an event payload shaped as `%{"key" => key}`; otherwise it clears the entire flash map.
- `DataDisplay.progress_bar/1` accepts optional integer `value` (default `nil`), positive `max`, and a closed data `state`; its current `clamp_progress(nil, max)` fabricates zero.
- `ShowcaseLive` is a connected dev/test-only parent, and `mount_showcase!/1` uses `live/2`, so it is the existing real LiveView seam for per-item default dismissal.
</interfaces>
