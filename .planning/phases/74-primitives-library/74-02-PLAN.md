<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| component class names to CSS | Primitive markup depends on owned CSS selectors for visual behavior. |
| browser event stream to tooltip behavior | Keyboard/pointer/focus events affect tooltip open/dismiss state. |
| source assets to packaged static assets | Source CSS/JS are copied into served `priv/static` assets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-74-05 | Tampering | primitive CSS source | mitigate | Static tests require `.obpt-root` scoping and token-backed primitive declarations; no host selectors or primitive raw visual values. |
| T-74-06 | Denial of Service | tooltip keyboard behavior | mitigate | Escape only updates scoped tooltip state and leaves focus on trigger; browser behavior tests in 74-05 prove no keyboard trap. |
| T-74-07 | Tampering | compiled assets | mitigate | Run deterministic asset build twice and require no diff in `priv/static/oban_powertools`. |
| T-74-08 | Spoofing | focus/hover styling | mitigate | Use tokenized focus-visible treatment and visible disabled/status channels so controls do not appear interactive when non-interactive. |
| T-74-SC | Tampering | package installs | accept | No package-manager install is planned; existing npm/Hex lockfiles are reused. |
</threat_model>
