<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller LiveView to primitive component | Parent code passes attrs, slots, labels, and IDs into shared primitives. |
| primitive component to browser DOM | HEEx-rendered markup becomes operator-facing controls and metadata. |
| primitive source to token CSS | Component-owned class names must resolve through scoped `.obpt-root` token CSS. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-74-01 | Tampering | `attr :rest, :global` passthrough | mitigate | Filter caller visual attrs in `visual_safe_rest/1`; render tests prove hostile visual attrs are absent while allowed identity/ARIA/data/phx/native attrs remain. |
| T-74-02 | Spoofing/Tampering | `link/1` and `button/1` semantics | mitigate | Keep navigation in `link/1` and mutations/actions in semantic buttons; tests assert link API does not create mutation-only link styling. |
| T-74-03 | Information Disclosure | icon/loading/status primitives | mitigate | Require icon-button labels and named loading/status text; decorative icons are hidden and visible labels remain present. |
| T-74-04 | Tampering/XSS | slots and story text rendered through primitives | mitigate | Use HEEx escaping and do not add raw HTML attrs or unsafe HTML injection APIs. |
| T-74-SC | Tampering | package installs | accept | No npm, Hex, pip, cargo, or other package-manager install is planned for Phase 74; package legitimacy checkpoint is not triggered. |
</threat_model>
