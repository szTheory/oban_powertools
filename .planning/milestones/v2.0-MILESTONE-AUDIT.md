5. App shell owns the nine-surface navigation, theme, actor, breadcrumb, and
   focus entry points.

7. Wave 1 pages compose the shared system without behavior regression.
8. Jobs/Forensics compose the shared system with URL/filter/detail continuity.
9. Batches/Workflows/Lifeline compose shared groups while preserving
   server-owned repair authority and Audit continuity.
