<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Host root layout -> Powertools shell | Host owns document root; Powertools owns only its nested LiveView root. |
| Browser -> initial theme state | Theme shell emits safe defaults before browser JS refines effective theme. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-71-11 | Tampering | `ThemeShell.live/1` | mitigate | Scope attributes and assets to `.obpt-root`; do not edit host root layout. |
| T-71-12 | Denial of Service | theme script loading | mitigate | Use external script inside root before content so persisted explicit choices can apply early without host bundler setup. |
| T-71-13 | Elevation of Privilege | router live_session | accept | Shell wiring does not change LiveAuth or permissions; tests keep existing routes green. |
| T-71-SC | Tampering | npm/pip/cargo installs | accept | No package installs are planned; Package Legitimacy Audit says none. |
</threat_model>
