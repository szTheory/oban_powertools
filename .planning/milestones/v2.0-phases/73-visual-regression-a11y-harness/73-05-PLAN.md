## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions to merge gate | CI job results decide whether `ci-gate` succeeds. |
| CI workspace to artifacts | Browser reports and JSON are uploaded for PR review. |
| Contributor commands to committed baselines | Local Docker update workflow can change expected PNGs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-73-09 | Tampering | `.github/workflows/ci.yml` `ci-gate` | mitigate | Add `visual_a11y` to `needs`, expose `VISUAL_A11Y`, and assert all required lane results in the existing fan-in loop. |
| T-73-10 | Information Disclosure | CI artifacts | mitigate | Upload only `playwright-report/`, `test-results/`, and generated manifest; avoid broad workspace archives and use short retention. |
| T-73-11 | Repudiation | Baseline update workflow | mitigate | Document Docker-only changed updates and require PR explanation for PNG baseline changes. |
| T-73-SC | Tampering | npm package installs | mitigate | CI uses `npm ci` against committed `package-lock.json`; no install-time package selection happens in workflow. |

No high-severity ASVS Level 1 threat remains unmitigated in this plan.
