<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller assigns -> AppShell HEEx | Actor/context/rest values render into shell HTML. |
| LiveView URI -> active nav | Current URI/path determines active item and breadcrumbs. |
| host auth module -> shell actor display | Existing auth module returns actor/principal data consumed as display-only shell copy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-76-01 | Tampering | `AppShell.nav_items/0` and test override | mitigate | Use a closed nav model, validate override shape, HEEx-escape text, and filter caller `class`/`style`. |
| T-76-02 | Spoofing | active-route computation | mitigate | Derive current path from LiveView `handle_params` URI hook and match against server-side route patterns. |
| T-76-03 | Information Disclosure | `actor_label/1` | mitigate | Use only `Auth.audit_principal/1` label/id or fallback copy; render no tenant/environment claims. |
| T-76-04 | Elevation of Privilege | shell nav/header | mitigate | Render links and theme buttons only; leave authorization/mutations in existing page LiveViews and LiveAuth helpers. |
| T-76-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs are planned. Stop for legitimacy review if an install appears. |
</threat_model>
