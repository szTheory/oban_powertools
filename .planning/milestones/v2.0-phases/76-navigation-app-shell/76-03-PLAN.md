<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CSS selectors -> host document | Library CSS must not style host UI outside `.obpt-root`. |
| browser events -> disclosure state | Click/key events mutate disclosure attributes in the shell. |
| theme controls -> localStorage/root attrs | Theme choice updates scoped root state and namespaced storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-76-04 | Denial of Service | mobile disclosure | mitigate | CSS hides collapsed nav at 320px; JS synchronizes state/aria and closes with Escape. Browser proof lands in 76-05. |
| T-76-05 | Information Disclosure | theme state | mitigate | Reuse `.obpt-root` and existing `data-obpt-theme-choice`; do not write host selectors or host storage keys. |
| T-76-06 | Tampering | scoped CSS | mitigate | Static tests reject host selectors, raw shell color literals, and unscoped `.obpt-app-shell` selectors. |
| T-76-07 | Repudiation | compiled assets | mitigate | Byte-stability tests prove source-to-static asset output is deterministic and reviewable. |
| T-76-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs are planned. Stop for legitimacy review if an install appears. |
</threat_model>
