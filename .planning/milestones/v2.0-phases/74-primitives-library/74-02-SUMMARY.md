## Decisions Made

- Added `--obpt-radius-round` and `--obpt-motion-ease-linear` to keep rounded pills/spinner motion token-backed instead of introducing raw primitive values.
- Kept tooltip behavior private to the existing `window.ObanPowertoolsTheme` IIFE; no new browser namespace or dependency was added.
- Used `data-obpt-tooltip-open` and `data-obpt-tooltip-dismissed` as the JS/CSS contract so Plan 74-05 can target behavior without relying on classes.
