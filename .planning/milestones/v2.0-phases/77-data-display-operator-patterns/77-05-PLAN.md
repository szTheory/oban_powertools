## ASVS L1 Threat Model

| ID | Threat | Severity | Mitigation and verification |
|----|--------|----------|-----------------------------|
| T-77-05-LEAK | Raw args leak via text, JSON formatting, copy, title, tooltip, data attrs, details, or expanded content | high | Components receive normalized output only; RedactedValue exposes none of those APIs; full-HTML sentinel matrix checks every channel and blocks completion. |
| T-77-05-ATTR | Caller attrs smuggle secrets or override code/redaction semantics | high | CodeBlock filters rest; RedactedValue has no global rest; semantic/visual/action attrs are component-owned and asserted in source/render tests. |
| T-77-05-XSS | Host policy strings/maps or stacktraces inject markup | high | Render escaped normalized binaries only, never `raw` APIs; HTML/script-like fixtures stay text in pre/code. |
| T-77-05-ATOM | Normalized map statuses/kinds create atoms or accept unknown domains | high | Tuple/map dispatch uses finite pattern matching and existing binary/atom fields without conversion; optional status presentation uses StatusTaxonomy's closed domain path. |
| T-77-05-DOS | Huge nested args/stacktraces cause server or browser denial of service | high | Parent normalizes/pretty-prints once; component treats output as bounded text, CSS constrains the viewport, stories use deterministic finite payloads, and tests avoid recursive rendering/decoding. |
</threat_model>
