# Phase 77 - Security

Threat-model-driven ASVS L1 audit for Phase 77 data-display operator patterns. The register was authored at plan time across `77-01-PLAN.md` through `77-09-PLAN.md`. This audit verifies only those 45 declared threats; it does not add a retroactive threat model. No implementation or test file was modified.

At ASVS L1, a mitigation closes a threat when the declared control is present in the cited implementation/evidence surface. The blocking threshold is `high`; no mitigation threat remains open. The three plan-time `accept` dispositions are documented in the Accepted Risks Log below.

## Scope

### Trust Boundaries

| Boundary | Data crossing | Evidence surface |
|---|---|---|
| External status/domain -> taxonomy/DOM | Atom or binary domains and states, including unknown and hostile strings | `status_taxonomy.ex`, taxonomy tests, taxonomy story |
| Caller assigns/rest attrs -> component DOM | Labels, rows, machine values, code, normalized display data, ARIA/data/phx attrs | `data_display.ex`, component tests |
| Normalized display policy -> ArgsViewer | Tuples/maps with availability, redaction, summary, status, and payload fields | normalized dispatcher, whole-HTML sentinel tests, browser disclosure scan |
| Parent collections -> rendered data surfaces | Table rows, timeline events, flash maps, large-result metadata | bounded catalog fixtures, responsive CSS, browser row-count checks |
| Phoenix flash -> DOM -> LiveView channel | Atom/binary keys, messages, tone/urgency, DOM identity, dismiss payload | FlashGroup/Toast source, component and connected LiveView tests |
| Optional progress -> semantic UI | Missing, nil, negative, in-range, and over-max measurements | ProgressBar source and component/browser tests |
| Optional test-support catalog -> packaged dev showcase | Missing/invalid `stories/0` output and malformed flash fixtures | package file set, fail-closed loader, five isolated child-process tests |
| Catalog -> manifest -> browser targets | Story metadata, selectors, snapshots, append order | generator, TypeScript and independent smoke validators, structure helper |
| CSS source -> packaged asset -> browser | Root-scoped selectors, bounded code overflow, responsive one-DOM reflow | source/package CSS equality, token/assets tests, browser behavior |
| Visual evidence -> reviewer trust | Ten stories x four themes x three projects | exact-120 verifier and screenshot set |
