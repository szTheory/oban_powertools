<threat_model>
## ASVS L1 Assets

- Job existence, full payload/error confidentiality, action authorization, opaque preview identity, durable Audit receipts, and deterministic back navigation.

## Trust Boundaries

| Boundary | Untrusted input / protected output |
|---|---|
| Detail URL -> resource load | forged ID/return params -> scoped authorized detail or uniform unavailable |
| Job/error/policy -> presenter | raw payload and exceptions -> finite redacted sections |
| Confirmation event -> Lifeline | forged action/reason/replay -> authorized preview-token execution |

## STRIDE Threat Register — blocking threshold: high

| Threat ID | Category | Severity | Disposition | Mitigation and verification |
|---|---|---|---|---|
| T-80-03-IDOR | Elevation of privilege | high | mitigate | Uniform unavailable output, server-owned target, and double authorization prevent enumeration/action forgery. |
| T-80-03-LEAK | Information disclosure | high | mitigate | Structural allowlists and sentinel tests exclude raw args/meta/output/errors/stacks/tokens before assigns. |
| T-80-03-REPLAY | Tampering | high | mitigate | Real single-use Lifeline previews, drift/expiry/consumed handling, and explicit fresh preview prevent replay. |
| T-80-03-NAV | Spoofing | high | mitigate | Return URLs are reconstructed from seven allowlisted params; opaque return_to is ignored. |
| T-80-03-TRUTH | Repudiation | high | mitigate | Exact finite receipts distinguish accepted, skipped, failed, and completed operations and link durable Audit evidence. |
| T-80-03-INJECT | Injection | high | mitigate | HEEx escaping, safe CodeBlock inputs, URL filtering, and no raw exception inspection block content injection. |
</threat_model>
